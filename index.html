About Me

Cloud Security Engineer

I’m a Cloud Security Engineer specializing in designing and securing AWS environments. My expertise covers identity and access management (IAM), encryption (KMS), network segmentation, and implementing robust security controls to protect cloud infrastructure from evolving threats. I approach every system with a “secure by default” mindset, ensuring that each layer, from networking to application, is hardened and resilient against attacks.

My experience spans practical cloud security implementations including JWT authentication, secure API design, rate limiting, password hashing, comprehensive audit logging, and threat detection. I am deeply engaged with DevSecOps practices, container and Kubernetes security, and infrastructure as code, building projects that reflect real-world enterprise architectures and industry best practices.

I take a holistic approach to cloud security, combining hands-on implementation with threat modeling, detection engineering, and operational excellence. My goal is to help organizations create secure, compliant, and highly available cloud environments where innovation can thrive without compromising safety, reliability, or performance.
